# Tic-Tac-Toe

A browser-based Tic Tac Toe game built with HTML, CSS, and JavaScript as part of **The Odin Project** Full Stack JavaScript curriculum.


## Features

- Two-player Tic Tac Toe gameplay
- Custom player names
- Win and tie detection
- Prevents moves on occupied squares
- Restart game button
- Responsive, interactive interface

## Built With

- HTML5
- CSS3
- JavaScript

## Concepts Practiced

This project focused on improving JavaScript architecture rather than complex game mechanics. Key concepts include:

- Factory functions
- Module pattern (IIFEs)
- Object-oriented program structure
- Separating game logic from DOM manipulation
- Event handling
- State management
- Minimizing global variables
